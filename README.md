# Data_Preprocessing
In this project, I used Python, Pandas, and NumPy to clean and preprocess a sample student dataset by handling missing values and removing duplicates. I also explored the data using charts, converted categorical values into numbers, and normalized numerical data to prepare it for machine learning.
# Tools and Technologies

Python

Pandas

NumPy

Matplotlib

Google Colab

# What I Did

Created a sample student performance dataset.

Checked and handled missing values using the median.

Removed duplicate records.

Analyzed the data using Pandas.

Created charts to understand the data.

Selected features for a machine learning task.

Converted Pass/Fail results into numerical values.

Normalized numerical data between 0 and 1.


# How to Run

Open Google Colab.

Create a new notebook.

Copy the Python code into a code cell.

Run the cell to perform the preprocessing steps and generate the output files.

# What I Learned

Through this project, I gained practical experience in Python, data cleaning, exploratory data analysis, categorical encoding, and normalization. It helped me understand why good-quality data is important before building a machine learning model.

# Note

This project uses a small sample dataset created for learning purposes. The results are intended to demonstrate basic data preprocessing techniques.
